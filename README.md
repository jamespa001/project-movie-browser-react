# Movie Browser Web Application

A responsive movie browsing and search web application powered by the OMDb API, featuring dynamic search queries, detail modal views, and interactive carousels.

## Features

- **Dynamic Movie Search**: Real-time search query handling against the OMDb database.
- **Detailed Modal Views**: Comprehensive movie details including ratings, cast info, and synopses.
- **Modern UI & Carousels**: Smooth responsive grid and carousel layouts built with Tailwind CSS.
- **Automated CI**: GitHub Actions integration ensuring dependency installation and build verification on every push.

## Tech Stack

- **Framework**: React, JavaScript
- **Styling**: Tailwind CSS
- **API**: OMDb API
- **Deployment**: Vercel
- **CI/CD**: GitHub Actions
